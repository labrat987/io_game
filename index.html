LPM: klik = zaznacz jednostkę, Shift+klik = dodaj/usuń, przeciągnięcie = lasso (Shift = dodaj)
PPM: klik = idź do punktu, przeciągnięcie z jednostki = TRASA (żółta), przeciągnięcie po terenie = FRONT (czerwona)
Tab: zmień priorytet celu zaznaczonych jednostek dystansowych (najbliższy / artyleria / ciężkie / najsłabszy)
